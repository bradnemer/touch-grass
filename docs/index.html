View on GitHub How it works
Three escalating interventions

From gentle nudge to locked door

Sitting motionless through a four-hour agent session is a you problem. touch-grass makes it a tooling problem — inspired by NPR's reporting on movement breaks.

🧘

Stretch reminders

After 60 minutes of active work, Claude opens its next reply by telling you to stand up — plus a macOS notification, in case the terminal is buried.

Level 1 · advisory
🚶

Walk suggestions

Claude just launched a 35-minute background job? It tells you so, and suggests you spend that exact window outside instead of watching logs scroll.

Level 2 · opportunistic
🚫

The penalty box

After 150 minutes of sustained work — tracked across every open Claude terminal — your prompts are blocked for a mandatory 30-minute break.

Level 3 · enforced
Yes, it has teeth

Sneak back early? +5 minutes.

The penalty box is shared global state — opening a second terminal doesn't help, it's the same clock. Every early-resume attempt extends the break:

🌱 TOUCH GRASS — mandatory break in progress. Early-resume attempt #2: +5 min added to your break. 23 min remaining — come back at 15:42.

Genuine emergency? Say I touched grass to override. It works — and it's logged to overrides.log, so your discipline audit is between you and your filesystem.

Under the hood

Hooks, not willpower

A skill can be ignored; hooks run in the harness itself. Plain Python 3 and a shared state file — zero dependencies.

HookWhat it does
SessionStart / SessionEndRegisters each terminal in shared global state
UserPromptSubmitHeartbeat · stretch nudges · the penalty gate (exit 2 blocks the prompt)
PostToolUseDetects background-task launches → walk suggestion
StopHeartbeat · fallback notification
Fair by design. Any 20-minute gap counts as an organic break — lunch resets the clock. Every threshold is configurable via /touch-grass. And the whole thing fails open: a touch-grass bug can never block real work. Only the penalty box can. On purpose.
